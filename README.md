# 妆造预选 · Studio（可安装 PWA）

化妆造型预选网页 / 手机 App：化妆师录入作品与服装饰品，客户上传头像做五官/肤色启发式分析（**参考**），系统推荐妆造并**直达试妆搭配**；客户「确认成套」后，化妆师在**还原台**按清单施工，可上传实拍看**还原度参考**。

本仓库为 **Progressive Web App（PWA）**，可「添加到主屏幕」。

## 技术栈

- Vite + React 19 + TypeScript
- React Router
- **PWA**：`vite-plugin-pwa`
- 数据：浏览器 `localStorage`（演示种子可开关）
- 演示图库：`public/assets/` 免版税实拍与短片（来源见 `public/assets/SOURCES.md`）
- 轻量埋点：`localStorage` 事件日志（可导出 JSON）
- 人脸分析 / 试妆图层 / 还原度：浏览器端启发式演示

## 快速启动

```bash
cd makeup-studio
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

```bash
npm run build
npm run preview
```

## 产品主路径（P0）

1. **首页**：双入口「我是客户 / 我是化妆师」；设置里可清除本地数据、载入演示、导出埋点。
2. **化妆师工作台** `/artist`：录入作品与库存；作品为空时客户会被拦截并引导到此。
3. **新客户** `/client`：上传前需同意隐私说明 → 分析（参考）→ **自动进入试妆**（Top1 写入草稿成套）。
4. **试妆搭配** `/try-on`：实时切换造型/服装/饰品 → **确认此成套**（`status: confirmed`）→ 跳转还原台。
5. **还原台** `/sessions`：优先展示已确认成套大图与勾选清单；无成套则引导回试妆；实拍还原度为沟通参考。

## 演示图库

作品和库存的演示内容是 Unsplash / Pexels 免版税照片，以及 3 段 Pexels 婚纱短片，用来代替色块占位。授权说明和每张文件的来源写在 `public/assets/SOURCES.md`。

打开应用时会核对演示库版本（`makeup-studio-demo-version`）。本机还是旧色块、或清空后从未载入过当前版本时，会自动换成 `/assets/` 里的实拍和短片。自己录入、标题对不上旧演示的项目会留下。

在当前版本里点过「清除全部本地数据」之后，空库保持为空，首页和工作台会给出「载入实拍演示图库」按钮。再点一次会覆盖作品、库存，并重置本地会话。

## 演示建议

1. 首页点「我是客户」（首次或旧色块库会自动换成实拍；若刚清除过数据，先点页面上的「载入实拍演示图库」）。
2. 同意隐私 → 上传正脸图 → 「开始分析并去试妆」。
3. 试妆页切换搭配 → 「确认此成套，去还原台」。
4. 还原台查看施工清单；可选上传实拍看还原度参考。
5. 验证空库：首页「设置与隐私」→ 清除全部本地数据 → 再点「我是客户」，应被拦到录入页。

## 隐私

- 头像与会话默认仅存本机；清除后不可恢复。
- 分析与还原度文案均标注「参考」，非医学/考核结论。
